# EVE Bot 刷怪脚本 v4

## 项目简介

基于模板匹配的 EVE Online 安卓模拟器自动化刷怪脚本，支持多分辨率自动适配。

## 目录结构

```
evebot/
├── rat_farm_v2.py       # 刷怪脚本主程序
├── adb_controller.py     # ADB连接和设备控制
├── screen_capture.py     # 屏幕截图和图像处理
├── template_matcher.py   # 模板匹配功能
├── ocr_recognizer.py     # OCR文本识别
├── annotate_tool.py      # 屏幕标注工具（独立程序）
├── mods/                 # 游戏模板图片
│   ├── __init__.py      # 模板映射模块
│   ├── anomaly_*.png    # 异常空间模板
│   ├── equip_*.png      # 装备按钮模板
│   ├── enemy_*.png      # 敌对目标模板
│   └── *.png           # 其他UI模板
├── screenshots/          # 截图保存目录
├── requirements.txt      # 依赖列表
└── README.md            # 项目说明
```

## 快速开始

### 运行脚本

```bash
python rat_farm_v2.py -d <设备ID> -l <循环次数>
```

参数说明：
- `-d, --device`: 设备ID（可通过 `adb devices` 查看）
- `-l, --loops`: 最大循环次数（默认999）

### 前置要求

1. 安卓设备开启USB调试模式
2. ADB已配置并能识别设备
3. 游戏已安装在设备上
4. 模板文件存放在 `mods/` 目录

## 装备点击策略

| 装备 | 点击策略 | 位置追踪 | 说明 |
|------|---------|---------|------|
| 母舰防御模块 | 一次性/跃迁 | ✓ | 普通模式只点1次 |
| 综合火控系统 | 一次性/跃迁 | ✓ | 同一位置不重复点 |
| 旗舰掠能器 | 每周期可重复 | ✓ | 每完整装备周期可点击 |
| 旗舰装甲维修器 | 状态驱动 | ✗ | 检测到损失才触发 |

## 检察官异常特殊流程

```
跃迁落地后:
    1. 在(3050,126)-(3197,1406)查找加速轨道图标 → 点击
    2. 再次在相同区域查找加速轨道 → 点击
    3. 查找激活按钮 → 点击
    4. 等待45s进入刷怪流程

防御模块点击规则:
    - 第1次: 落地锁定后立即
    - 第2次: 首次后180s
    - 第3次: 首次后360s

退出流程:
    - 8轮无目标退出
    - 在特殊区域点击异常图标筛选按钮
    - 重置inspector_mode
```

## 分辨率适配

脚本自动检测设备分辨率并按比例缩放坐标：

```
参考分辨率: 3200 x 2136

支持的分辨率示例:
| 分辨率 | 缩放比例 |
|--------|---------|
| 720p   | (0.400, 0.337) |
| 1080p  | (0.600, 0.506) |
| 1440p  | (0.800, 0.674) |
| 参考   | (1.000, 1.000) |

启动时输出:
[分辨率] 参考: 3200x2136, 实际: 1920x1080, 缩放: (0.600, 0.506)
```

## 配置参数

在 `rat_farm_v2.py` 的 `__init__` 中可调整：

```python
# 时间参数
self.undock_wait = 25           # 离站等待
self.anomaly_click_wait = 3     # 点击异常后等待
self.warp_wait = 45             # 跃迁后等待
self.one_key_lock_interval = 10  # 一键锁定最小间隔
self.no_target_timeout = 16      # 无目标超时
self.equip_click_interval = 3   # 装备点击间隔

# 检测参数
self.enemy_check_interval = 20   # 敌对检测间隔
self.status_check_interval = 30  # 状态检测间隔
self.inspector_activate_wait = 45  # 检察官激活等待
self.inspector_defense_interval = 180  # 检察官防御间隔
```

## 标注工具

```bash
python annotate_tool.py
```

功能：
- 加载截图或ADB截屏
- 框选区域标注
- 保存为JSON格式
- 支持截图链记录

## 注意事项

1. 确保模板图片清晰且与实际分辨率匹配
2. 首次运行会自动检测设备分辨率
3. 无线连接需确保ADB TCP模式已开启
4. 模板匹配阈值默认0.7，敌对检测0.6
