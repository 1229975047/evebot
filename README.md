# EVE Bot 刷怪脚本 v4

## 项目简介

基于模板匹配的 EVE Online 安卓模拟器自动化刷怪脚本，支持多分辨率自动适配。

## 目录结构

```
evebot/
├── rat_farm_v2.py       # 刷怪脚本主程序
├── adb_controller.py     # ADB连接和设备控制
├── screen_capture.py     # 屏幕截图和图像处理
├── template_matcher.py   # 模板匹配功能
├── ocr_recognizer.py     # OCR文本识别
├── annotate_tool.py      # 屏幕标注工具（独立程序）
├── mods/                 # 游戏模板图片

│   ├── anomaly_*.png    # 异常空间模板
│   ├── equip_*.png      # 装备按钮模板

├── screenshots/          # 截图保存目录

```

## 快速开始

### 运行脚本

```bash
python rat_farm_v2.py -d <设备ID> -l <循环次数>
```

参数说明：
- `-d, --device`: 设备ID（可通过 `adb devices` 查看）
- `-l, --loops`: 最大循环次数（默认999）

### 前置要求

1. 安卓设备开启USB调试模式
2. ADB已配置并能识别设备
3. 游戏已安装在设备上
4. 模板文件存放在 `mods/` 目录


## 分辨率适配

脚本采用**坐标归一化**方案，自动检测设备分辨率并按比例缩放所有坐标和模板匹配区域。

### 参考分辨率

脚本使用 **3200 x 2136** 作为参考分辨率（设计分辨率）。所有模板图片和检测区域坐标均基于此分辨率设计。

### 支持的分辨率

脚本支持任意分辨率，启动时自动计算缩放比例：

| 分辨率 | 屏幕宽高比 | 缩放比例 (scale_x, scale_y) |
|--------|-----------|----------------------------|
| 720p (1280×720) | 16:9 | (0.400, 0.337) |
| 1080p (1920×1080) | 16:9 | (0.600, 0.506) |
| 1440p (2560×1440) | 16:9 | (0.800, 0.674) |
| 4K (3840×2160) | 16:9 | (1.200, 1.011) |
| 参考 (3200×2136) | ~16:10 | (1.000, 1.000) |

### 分辨率检测机制

1. **自动检测**：启动时通过 ADB 命令 `dumpsys window displays` 获取实际显示尺寸
2. **比例计算**：`scale_x = 实际宽度 / 参考宽度`, `scale_y = 实际高度 / 参考高度`
3. **坐标转换**：所有预设坐标和检测区域在运行时自动乘以缩放比例

### 启动时分辨率信息输出

```
[分辨率] 参考: 3200x2136, 实际: 1920x1080, 缩放: (0.600, 0.506)
```

### 注意事项

- 模板图片应基于参考分辨率 3200x2136 制作
- 模拟器分辨率建议设置为 3200x2136 以获得最佳匹配效果
- 不同宽高比的屏幕可能需要调整模板或检测区域
- 如果发现识别不准确，可尝试调整模拟器分辨率或重新制作模板

## 配置参数

在 `rat_farm_v2.py` 的 `__init__` 中可调整：

```python
# 时间参数
self.undock_wait = 25           # 离站等待
self.anomaly_click_wait = 3     # 点击异常后等待
self.warp_wait = 45             # 跃迁后等待
self.one_key_lock_interval = 10  # 一键锁定最小间隔
self.no_target_timeout = 16      # 无目标超时
self.equip_click_interval = 3   # 装备点击间隔

# 检测参数
self.enemy_check_interval = 20   # 敌对检测间隔
self.status_check_interval = 30  # 状态检测间隔
self.inspector_activate_wait = 45  # 检察官激活等待
self.inspector_defense_interval = 180  # 检察官防御间隔
```

## 注意事项

1. **分辨率适配**：模板图片基于参考分辨率 **3200x2136** 制作，脚本会自动根据实际设备分辨率进行缩放
2. **首次运行**：启动时会自动检测设备分辨率并输出缩放比例信息
3. **ADB连接**：无线连接需确保ADB TCP模式已开启（`adb tcpip 5555`）
4. **模板匹配阈值**：默认匹配阈值0.65，敌对目标检测阈值0.75，可在代码中调整
5. **性能优化**：采用截图缓存机制，减少重复截图操作；战斗循环使用多线程并行处理
6. **异常空间优先级**：大型异常 > 检察官异常 > 中型异常 > 小型异常
7. **紧急撤退**：检测到敌对玩家时会自动执行紧急撤退程序
8. **防御模块**：有独立的状态管理，激活后172秒自动关闭，关闭后60秒冷却

## 故障排除

| 问题 | 可能原因 | 解决方案 |
|------|---------|---------|
| 未找到异常模板 | 分辨率不匹配或模板图片缺失 | 检查设备分辨率，确保模板文件存在于`mods/`目录 |
| 跃迁按钮等待超时 | 网络延迟或游戏卡顿 | 增加`warp_wait`参数，检查网络连接 |
| 一键锁定不触发装备点击 | 首次锁定标志未重置 | 检查战斗循环逻辑，确保`first_lock_after_warp`正确重置 |
| 脚本运行缓慢 | 截图频繁或OCR初始化耗时 | 检查截图频率设置，OCR采用懒加载机制 |
